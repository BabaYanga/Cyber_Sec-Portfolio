## 📜 How to Use This Repository

Each project is documented in a dedicated markdown file with the following structure:

1. **Objective** – Overview of the project's purpose  
2. **Tools & Commands** – Software or commands used  
3. **Process** – Step-by-step execution  
4. **Result** – Outcome or findings  
5. **Key Takeaways** – Lessons learned and real-world applications  

See example: [Password Cracking with John the Ripper](projects/password-cracking-jtr.md)
